Resumo sobre o uso do CSS

CSS (Cascading Style Sheets) é a linguagem usada para definir o estilo de páginas web.

  1. - **O que faz**: controla cores, fontes, tamanhos, espaçamentos, alinhamentos, bordas e layout dos elementos HTML.
  2. - **Como funciona**: aplica regras a elementos HTML usando seletores como `tag`, `.classe` e `#id`.
  3. - **Principais vantagens**:
  4. - separa estilo do conteúdo,
  5. - facilita manter aparência consistente em várias páginas,
  6. - permite criar interfaces responsivas e visualmente atraentes.
  7. - **Exemplo básico**:
  8. - HTML define a estrutura,
  9. - CSS define a apresentação.

### Uso comum

  1. - definir estilo global (`body`, `h1`, `p`)
  2. - personalizar componentes (`menu`, `botões`, formulários)
  3. - criar layouts com `flexbox` e `grid`
  4. - adaptar para diferentes tamanhos de tela com `media queries`

Em resumo, o CSS transforma o HTML simples em páginas bonitas e organizadas, controlando a aparência e a experiência visual do site.

Css Inline

O CSS inline é uma forma de aplicar estilos diretamente a um elemento HTML usando o atributo `style` `/style`. Ele é útil para aplicar estilos específicos a um único elemento atraves de um seletor `h2{}` e dentro da chave do seletor, colocamos o bloco `color: red;`,ainda dentro do seletor, eu também poderia mudar a posição do texto com o bloco `text-align: center`, mas não é recomendado para grandes projetos devido à dificuldade de manutenção e falta de reutilização.

posso colocar um seletor com duas coisas ou mais tmabém, `h1,h2{}` e dentro colocar um bloco`text-transform: uppercase;` para deixar h1 e h2 com caixa alta de uma única vez

caso queira uma lista especifica que está dento do nav, basta coloca um seletor `nav li{}`

vamos colocar um bloco nessa lista para ela ficar em uma linha, `display: inline; `

posso criar uma classe como seletor `class="destaque"`, coloco essa classe dentro de uma tag e paragrafo e dentro de uma tag de h2 especificos, para mudar somente aquilo que estiver com essa classe, o seletor da classe se inicia com um ponto `.destaque{}`

Vantagens do CSS inline:

  1. - Fácil de aplicar para estilos rápidos e específicos.
  2. - Sobrescreve estilos de folhas externas ou internas.

Desvantagens do CSS inline:

  1. - Dificulta a manutenção, especialmente em projetos grandes.
  2. - Não permite reutilização de estilos, levando a código redundante.
  3. - Pode tornar o HTML desorganizado e difícil de ler.

Em geral, é melhor usar CSS externo ou interno para manter o código limpo e fácil de gerenciar, reservando o CSS inline para casos específicos onde uma rápida personalização é necessária.

CSS Externo

O CSS externo é uma forma de aplicar estilos a uma página web usando um arquivo separado com a extensão `.css`. Ele é recomendado para projetos maiores, pois permite a reutilização de estilos e facilita a manutenção do código.

Vantagens do CSS externo:

  1. - Permite a reutilização de estilos em várias páginas, promovendo consistência visual.
  2. - Facilita a manutenção, pois as alterações no arquivo CSS afetam todas as páginas vinculadas.
  3. - Mantém o HTML limpo e organizado, separando estrutura e estilo.

Desvantagens do CSS externo:

  1. - Requer uma solicitação HTTP adicional para carregar o arquivo CSS, o que pode afetar o tempo de carregamento da página.
  2. - Se o arquivo CSS estiver indisponível (por exemplo, devido a um erro de caminho), a página pode ser exibida sem estilos, resultando em uma aparência desorganizada.

Em geral, o CSS externo é a melhor prática para a maioria dos projetos web, especialmente aqueles com múltiplas páginas, pois promove a organização e facilita a manutenção do código.
