A linguagem é de marcação de textos composta por tags, o segredo é conhecer tags como as:

1. Estrutura Básica

"!DOCTYPE html": Usa a última versão do html 5

"html": Define que este é um documento HTML(tag raiz, as outras ficam dentro dela).

"head": Contém os metadados da página (título, links para CSS, scripts), que não ficam visíveis ao usuário.

"meta charset="UTF-8": serve para reconhecer simbolos do teclado ABNT principalmente acentuação

"title": Define o título da página que aparece na aba do navegador.

"body": Contém todo o conteúdo visível da página, como textos, imagens e vídeos.

3. Links e Mídia

"a": Cria um link ou âncora para outra página ou seção. Colocando o href junto do a você cria um texo clicavel para o link

" a href="https:www.youtube.com" "

" a target="_blank" href="https:www.youtube.com" " o link vai abrir em uma nova página da web

Link

Clique aqui para acessar o youtube:

"img": Exibe uma imagem, essa tag é auto contida, não precisando de abertura e fechamento, precisa do src que é a onde está a imagem e fecha a tag ficando assim: "tag img src="img/html.png / tag"

podemos dar um titulo alternativo "alt" para a imagem, caso tenha algum problema futuro onde fica a imagem, então é apenas substituir por uma igual

"tag img src="img/html.png" alt="Logo Html" / tag"

"hr": coloca uma linha na página

4. Estrutura Semântica

Essas tags organizam o layout e ajudam motores de busca (como o Google) a entender a página

"header": Cabeçalho de uma página ou seção

"nav": Seção com links de navegação/menu.

"main": Conteúdo principal do corpo da página.

"section": Define uma seção ou bloco de conteúdo.

"footer": Rodapé da página

6. Formulários

"form": Cria o formulário em si

"input": Cria campos de entrada (texto, senha, botões).

"label": Define o rótulo para um campo de formulário.

"button": Cria um botão clicável

Além das tags, existem atributos, que servem para mudar o comportamento padrão de uma tag

(colocando o nome do atributo, o igual entre aspas o valor que eu quero) como:

" h6 align="center" "

"align="center"""colocado dentro da tag para o texto ficar centralizado

" h6 align="right" "

"align="right"""colocado dentro da tag para o texto ficar alinhado na direita

" h6 align="left" "

"align="left"""colocado dentro da tag para o texto ficar alinhado na esquerda
